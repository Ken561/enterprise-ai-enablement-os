# LevelUp 301 — Agentic AI

**Audience:** Advanced practitioners ready to design or work with agentic workflows — systems that take multiple steps, call tools, or act with some autonomy.

**Goal:** Give practitioners the design vocabulary and judgment to build or evaluate an agentic workflow responsibly — not just to use one someone else built.

## Illustrative Topics

- The difference between a single-turn AI interaction and an agentic workflow with defined steps, tool calls, and checkpoints
- Designing acceptance criteria for an agentic task before building it
- Where human review checkpoints belong, and why autonomy should be earned incrementally rather than granted by default
- Escalation-path design: what happens when the agent can't complete a step or produces a low-confidence result
- Grounding agentic outputs in retrieval (RAG) rather than model memory alone, and why that matters for accuracy

## Completion Signal

A participant can sketch the acceptance criteria, human review checkpoints, and escalation path for a proposed agentic workflow — the same structure used to design and build the Claude Code Issue Capture Agent, a production agentic workflow spanning 26+ PRD sections.

## Format Notes

Delivered as a workshop with a real design exercise, not a lecture — participants leave with a draft design for a workflow relevant to their own team, reviewed against the same [Governance Framework](../governance/governance-framework.md) any production use case would go through.
